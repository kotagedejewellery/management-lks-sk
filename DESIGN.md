# Dashboard reporting

Dashboard Admin keeps programme health readable before comparison. A single **Jenis LKS** selector scopes the summary, department bars, and follow-up link together: Semua jenis LKS, Reguler, or Magang.

The selector is a normal labelled control, uses the existing paper-and-evergreen system, and expands to the available width on mobile. It does not imply a different passing threshold: Magang has its own activity targets, while completion remains governed by the participant's period threshold.
